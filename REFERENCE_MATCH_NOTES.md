# Approved design reproduction

The homepage is implemented using actual React/Next.js markup and CSS, NOT a screenshot as a whole-page background. The approved green-and-white image is the visual direction and is supplied separately as `reference/approved-homepage.png`. Photos in `public/images` are extracted from the approved generated mockup. All navigation, service tabs, carousel controls, FAQ accordions, mobile menu, and enquiry CTAs are editable and interactive.

The image reference was generated at 724 x 2171 pixels; perfect source-pixel identity on all screen sizes is impossible because real browsers render responsive type and layout differently. The desktop layout maintains the same section order, palette, card treatment, photographic assets and approximate section proportions. Replace raster crops with licensed high-resolution originals before a production launch.
